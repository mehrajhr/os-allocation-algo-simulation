# 🧠 OS Memory Allocation Simulator

An interactive web-based simulator illustrating operating system memory allocation algorithms (First Fit, Best Fit, and Worst Fit) using vanilla HTML, CSS, and JavaScript.

---

## 🚀 Live Demo
* **Live Website:** https://mehrajhr.github.io/os-allocation-algo-simulation/

---

## ✨ Features
* **Multiple Allocation Algorithms:** Supports First Fit, Best Fit, and Worst Fit strategies.
* **Custom Inputs:** Dynamically configure memory block sizes and process sizes using comma-separated values.
* **Visual Representation:** Clean color-coded UI cards showing block states (`Free` vs. `Occupied`) and remaining spaces.
* **Zero Dependencies:** Built completely with pure vanilla JavaScript, HTML5, and CSS3 for high performance.

---

## 🛠️ Tech Stack
* **Languages:** HTML5, CSS3, JavaScript (ES6+)
* **Concepts:** Operating Systems, Continuous Memory Allocation, Algorithmic Search
